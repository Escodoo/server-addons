## Configuration

The users that are in the group "Technical Administrator (Limited)" can access
the settings and technical menus but can't access purchase orders, sales orders,
account moves, employees or contracts. You must remove the following permissions
from the user:

- Sales / Administrator
- Purchase / Administrator
- Invoicing / Administrator
- Employees / Administrator
- Contracts / Administrator

Besides the restrictions in Sales, Purchase, Invoicing, Employees and Contracts, the
module makes users, groups and record rules read-only, and restricts access to system
parameters.
