Usage
=====

To use this module, you need to:

-  Open Settings > Tier Definition and create a new definition.
-  Select the model, the From State, and the To State for the
   validation.
-  When a user tries to change the state of a record, if there is a
   definition for the current state and the target state, a validation
   request will be created automatically.
-  The Request Validation button will be hidden.
